# FitPlanner – Fitness Planning App

A desktop fitness planning application built using C# and .NET (Windows Forms).

## Features
- Workout planning
- Progress tracking
- Diet management interface
- User-friendly dashboard

## Tech Stack
- C#
- .NET (WinForms)

## How to Run
1. Open project in Visual Studio
2. Build and run the solution
